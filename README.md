# Divicious Deli & Coffee Shop — website rebuild

Static, zero-dependency site for Divicious Deli & Coffee Shop (128 E Main St., Lakeland, FL).

- `npm start` serves `site/public` on `$PORT` (default 4620).
- Menu content: `site/public/js/menu-data.js`.
- Page shells: edit `site/src/*.main.html` / `site/src/shell.html`, then `npm run build`.
